📖 Holy Bible Quiz

Holy Bible Quiz is a Python-based command-line application designed to help users test and improve their knowledge of the Bible in a fun and interactive way. The project includes two main quiz modes: Choose by Verse, where players identify the correct Bible reference from a displayed verse, and General Questions, where players answer multiple-choice Bible questions across Easy, Medium, and Hard difficulty levels. The program uses JSON files to store the KJV Bible dataset and quiz questions, while Python's random module is used to generate different questions for each game. It also includes score tracking, random question selection, instant feedback for correct and incorrect answers, and an About the Rules section. This project was created to practice Python programming concepts such as functions, loops, conditionals, lists, dictionaries, JSON data handling, and randomization while creating a fun way to study and review Bible knowledge. 📖🙏💻
